# Программа версии 1.0.0

Дата фиксации: 2026-10-09. Статус: утверждено.

Большая программа переработки панели, AI-слоя и Telegram-бота. Первый релиз —
**1.0.0** (каркас UI/UX и человеческий язык), дальше фазы идут по семантике:
фичи — minor (1.1.0, 1.2.0…), фиксы — patch. После завершения программы —
обычное семантическое версионирование.

## Принципы

- **Человеческий язык**: никаких `word_word`, кодов стратегий и технических
  ярлыков в UI и ответах AI; простые формулировки, числа с «₽», понятные причины.
- **Минимум кликов**: всё важное — в один экран, действия — рядом с объектом.
- **Live**: обновления без перезагрузки (WebSocket + резервный polling).
- **Персистентность AI**: все ответы, сводки и обоснования сохраняются и
  переиспользуются; кэш с инвалидацией по событиям.
- **Готовность к агентам**: данные, правила и фидбек собираются так, чтобы
  позже подключить локальные модели и субагентов без переделки.

## Зафиксированные решения

- **Live**: WebSocket — основной канал, polling остаётся как fallback.
- **Чат-ассистент v1**: аналитика + действия с подтверждением (запуск обхода,
  черновик правки — детерминированный или ручной, очистка алертов, генерация
  дайджеста). Каждое действие — confirm-кнопка, всё логируется.
- **Провайдер ИИ**: сейчас DeepSeek API. Локальные модели — позже; заранее
  делаем переключаемый `LLM_BASE_URL` (OpenAI-совместимый) и маршрутизацию задач.
- **Бренды/фацеты**: AI-разметка `brand/model/color/type` с кэшем в БД.
- **Датасет**: логируем промпты/ответы, действия и фидбек (палец вверх/вниз +
  комментарий) — база для будущего LoRA и eval.
- **Локального рантайма в этой программе нет** — только подготовка (фаза 1.5.0).

## Фазы

### v1.0.0 — Каркас UI/UX и человеческий язык

- AppShell: сайдбар (Дашборд, Поиски, Объявления, Аккаунты, Алерты, AI) +
  хедер (поиск, колокольчик, чат, статус, расходы).
- Единые UI-примитивы: Page/Card/Table/Chip/Tabs/Skeleton/EmptyState/Modal.
- Единый словарь терминов (фронт и бэк): стратегии, категории, статусы, задачи
  AI, причины исключений — человеческие названия в одном месте.
- Промпты v2: «пиши простым языком, без кодов и жаргона» для дайджеста,
  модерации, правок, фильтров, советов по цене; человеческие тексты ошибок.
- Дашборд-виджеты (система, AI-расход/баланс, свежие алерты, активные обходы,
  экономика правок); страница поиска табами (Обзор/Выдача/Дайджест/Продавцы).
- Критерий готовности: старые сценарии работают, тексты человеческие, единый
  каркас без дублей стилей; tsc/build/тесты зелёные.

### v1.1.0 — Live (WebSocket) и алерты в хедере

- Redis pub/sub `events` → FastAPI WS `/api/v1/ws` → `EventProvider` на фронте.
- События: crawl.*, alert.new, edit.*, reprice.run, sync.*, digest.new.
- Убираем polling в crawl/digest/proxy/system, fallback — polling.
- Колокольчик: badge, дропдаун последних алертов, ack / «прочитать все».

### v1.2.0 — AI-центр: артефакты и чат-ассистент

- Таблицы `ai_artifacts` (digest, advice, reprice, filters, карточка SKU),
  `chat_sessions`, `chat_messages`, `ai_feedback`.
- Кэш Redis с инвалидацией по событиям (изменилась цена → advice пересчитать).
- Чат из хедера: стриминг, инструменты (система, поиски, SKU, алерты, расходы,
  правки), ссылки-цитаты на объекты, **«Очистить контекст»**, архив чатов,
  учёт стоимости в `llm_runs` (task=chat).

### v1.3.0 — Telegram 2.0

- HTML-разметка, человеческие шаблоны уведомлений, deep links в панель
  (`PANEL_PUBLIC_URL`), кнопки: открыть поиск/SKU/правки, запустить обход,
  очистить алерты.
- Подписки по типам уведомлений, постраничные меню, быстрые действия.

### v1.4.0 — Бренды, фацеты и дайджест по бренду

- AI-теги объявлений (brand/model/color/type) батчами, кэш в БД.
- Чипы-фильтры в выдаче (`?brand=Devialet`), фильтр «чисто Devialet» внизу
  списка; фацеты в «Наших объявлениях».
- Дайджест по бренду/фильтру как отдельный сохранённый артефакт.

### v1.5.0 — Подготовка к агентам

- Переключаемый `LLM_BASE_URL` (OpenAI-совместимый: Ollama/MLX/vLLM) для
  будущего локального рантайма; маршрутизация задач (чат/агенты — локально,
  тяжёлое — облако), fallback.
- **Playbooks по категориям**: критерии владельца (целевые цены, эталонные
  конкуренты, минимальные продажи/вымывание, приоритеты) — CRUD в панели.
- Агенты-роли MarketAgent(category) на DeepSeek: данные + playbook + инструменты
  → структурированный отчёт (цены, тренд, предложения правок); ночной прогон,
  отчёты в `ai_artifacts` + алерты.
- Сбор датасета: промпты/ответы/фидбек → JSONL для будущего LoRA, eval-набор.

### v1.6.0 — Субагенты

- Оркестратор + параллельные агенты по категориям, консенсус по цене,
  подтверждение человеком, журнал решений со ссылками на данные.

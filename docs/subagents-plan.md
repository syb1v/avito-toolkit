# План развития субагентов (после v1.6.0)

Дата: 2026-10-09. Статус: зафиксировано, к реализации после накопления датасета.

Программа v1.0.0–1.6.0 завершена: в продукте уже есть AI-артефакты, чат,
плейбуки категорий, оркестратор субагентов с консенсусом и журналом решений,
экспорт датасета и переключатель на локальный рантайм (`LLM_LOCAL_BASE_URL`).
Этот документ — план следующего этапа: локальные агенты по категориям.

## Цель

Пять–шесть агентов, каждый анализирует свою категорию (например: Devialet,
Bang & Olufsen, экшн-камеры, фототехника…), по критериям владельца, на своих
данных — и выдаёт анализ цен и предложения, которым можно доверять без ручной
перепроверки. По образцу прежнего ручного процесса: на вход данные (конкуренты,
целевые цены, количество продаж/выбытие за период), на выход — план цен.

## Принципы

- **Данные решают, LLM объясняет**: числа (медианы, выбытие, матчи, наши цены)
  считаем детерминированно; модель формулирует вывод и проверяет логику.
- **Плейбук — единственный источник критериев**: целевые цены, эталонные
  конкуренты, минимальные продажи/вымывание, приоритеты. Меняется в панели,
  агент читает при каждом прогоне.
- **Человек в контуре**: предложения применяются только после подтверждения
  (журнал решений уже есть).
- **Локально, когда появится железо**: Mac Studio → MLX-LM/Ollama/vLLM,
  OpenAI-совместимый endpoint; облако как fallback.

## Этапы

### S1. Накопление датасета (сейчас — идёт автоматически)

- Уже пишутся: `llm_runs` (задачи, токены, стоимость), `ai_artifacts` (советы,
  дайджесты, отчёты агентов, консенсусы), `chat_messages`, `ai_feedback`.
- Добавить (малый объём работ): кнопки 👍/👎 и комментарий к советам по цене
  и отчётам агентов; автосохранение «до/после» для каждой правки (уже есть в
  `listing_edits` + `ai_summary`) и результата применения (цена на Авито).
- Экспорт: `GET /ai/dataset/export` (JSONL) — артефакты + фидбек + ответы чата;
  расширить парами «вход → правильный ответ» по мере ручных правок.

### S2. Локальный рантайм

- Железо: Mac Studio (M-серия Ultra). Запуск: MLX-LM или Ollama.
- Модели (по объёму памяти):
  - 64 ГБ: Qwen3-30B-A3B (MoE, быстрый, RU+JSON), Gemma 3 27B (лёгкие задачи).
  - 128 ГБ: + Qwen3-32B, DeepSeek-R1-Distill-70B (reasoning для сложных сводок).
  - 256+ ГБ: + Qwen3-72B.
- Эмбеддинги: bge-m3; реранкер: bge-reranker-v2-m3 (для поиска по истории).
- Подключение: `LLM_LOCAL_BASE_URL=http://<mac>:11434/v1`, `LLM_LOCAL_MODEL=qwen3:30b`
  в серверном `.env` — задачи переключаются автоматически (код готов).
- Роутинг: чат/агенты — локально; тяжёлые разовые сводки — облако как fallback.

### S3. Агент категории v2 (глубокий анализ)

- Вход: выдача по поискам категории (активные, перцентили), история медиан,
  матчи наших SKU, выбытие (сколько снято/продано за 7/30 дней), конкуренты из
  плейбука, себестоимость, прошлые правки и их эффект.
- Выход (структурировано): вердикт по рынку, диапазон цен, предложения по нашим
  SKU с обоснованием, риски, чек-лист проверки (данных достаточно / мало).
- Добавить инструменты: тренд по дням, сравнение конкурентов из плейбука,
  «сколько стоит наша позиция в выдаче», история наших цен и реакция рынка.

### S4. Обучение (LoRA) и eval

- Не «обучать с нуля»: база — RAG + few-shot + правила + плейбуки.
- LoRA на накопленном JSONL (MLX): цель — стабильный формат отчёта и «голос»
  владельца (какие цены правильные, как объяснять).
- Eval-набор: 50–100 исторических ситуаций «данные → что сделал бы владелец»;
  метрики: попадание в целевой диапазон, корректность чисел, полезность причин.
- Регулярный прогон eval перед сменой модели/промптов.

### S5. Оркестратор v2

- Сейчас: параллельные агенты → один консенсус → подтверждение.
- Дальше: агент-критик (проверяет числа и логику консенсуса), конфликт-резолвер
  (если категории пересекаются), «дневник рынка» (что изменилось с прошлого
  прогона), автогенерация задач («данных мало — обойди конкурента X»).
- Расписания: отчёты — ночью; консенсус — после отчётов; применение — только
  человеком (или авто-применение в пределах ±5% при включённом тумблере).

### S6. Продуктовое

- Страница «Агенты»: список агентов, последние отчёты, динамика цен категории,
  эффективность прошлых решений (что применили → как изменились просмотры/цены).
- Уведомления: отчёт агента в Telegram + кнопка «Одобрить план» прямо в боте.
- A/B: для части SKU применять консенсус, для части — старый алгоритм; сравнить.

## Что понадобится от владельца

- Мак-студия (конфиг памяти), доступ к ней с сервера (VPN/туннель).
- Критерии по каждой категории (заполняются в плейбуках в панели).
- Фидбек по предложениям (палец вверх/вниз) — это топливо для LoRA.
